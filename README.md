# دفتر — نظام المحاسبة المشترك (V 2.0)

نظام محاسبة عربي (RTL) بثلاث عملات مستقلة (USD / TRY / SYP) لإدارة المدخلات والمصروفات والديون، مع تقارير شهرية وسجل تعديلات كامل قابل للاستعادة.

**الجديد:** البيانات لم تعد محلية في متصفح كل مستخدم (IndexedDB)، بل تُحفظ سحابيًا، لذا **أي تعديل يقوم به أي شخص يظهر لكل من يملك الرابط** من أي جهاز.

## 🚀 النشر على GitHub + Netlify
اقرأ **[SETUP.md](SETUP.md)** — 5 دقائق:
1. أنشئ قاعدة Firebase Realtime Database مجانية.
2. الصق رابطها في `js/config.js` (السطر `firebaseDatabaseUrl`).
3. ارفع الملفات إلى GitHub؛ Netlify ينشر تلقائيًا.

## الميزات المكتملة
- نظرة عامة: بطاقات الأرصدة لكل عملة، رسم حركة الأموال لـ 6 أشهر، توزيع المصروفات، أحدث العمليات.
- المدخلات (بعدة عملات في إدخال واحد) والمصروفات (مع إرفاق حتى 5 صور).
- الديون: سجل مستقل لكل مدين بالعملات الثلاث، مع تعديل/حذف/استعادة.
- التقارير الشهرية مع بحث وتصفية وتصدير CSV.
- سجل التعديلات: كل إضافة/تعديل/حذف محفوظ، مع استعادة المحذوفات ومجموعات التصفير.
- لوحة التحكم: اسم مساحة العمل، أسماء العملات، التصنيفات، تصفير الحسابات، النسخ الاحتياطي (تصدير/استيراد JSON).
- **تخزين سحابي مشترك** + **مزامنة حية** كل 15 ثانية وعند العودة للتبويب أو عودة الاتصال.
- الوضع الليلي، تصميم متجاوب للجوال.
- صفحة `download.html` لتنزيل المشروع كاملًا كـ ZIP منظم جاهز للرفع.

## طبقة التخزين (`js/storage.js`)
تختار المصدر تلقائيًا حسب `js/config.js`:

| المصدر | متى يُستخدم | الاستضافة |
|---|---|---|
| **Firebase Realtime Database** (REST) | عند وضع `firebaseDatabaseUrl` | GitHub Pages، Netlify، أي استضافة ثابتة |
| **واجهة `tables/`** (منصة Genspark) | عند ترك الرابط فارغًا | نشر من تبويب Publish في Genspark |

في Firebase: البيانات تحت الجذر `daftar/` بأربع مجموعات `records` `debts` `history` `settings` + `meta/version` لاكتشاف التعديلات من الأجهزة الأخرى. كل حفظ يتم بـ PATCH واحد متعدد المسارات (كل التغييرات معًا).

في `tables/`: 4 جداول بنفس الحقول (`id, kind, title, date, payload, updated`) والعنصر الكامل كـ JSON في `payload`.

الحذف في التطبيق منطقي (`deletedAt`) وقابل للاستعادة.

## ملاحظات
- **الأمان:** لا كلمة مرور؛ كل من يملك الرابط يستطيع التعديل. شاركه مع من تثق به فقط.

- **نقل البيانات القديمة:** صدّر JSON من النسخة القديمة واستورده من لوحة التحكم في الجديدة.
